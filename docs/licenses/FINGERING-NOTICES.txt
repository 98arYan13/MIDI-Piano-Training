# Python inference dependencies

The local inference runtime uses CPython 3.11.9 and PyTorch 2.8.0+cpu. PyTorch
is distributed under its BSD-style license; its bundled third-party notices
are included in the `torch` wheel. The pinned runtime dependencies and their
license identifiers are: filelock (Unlicense), typing_extensions
(PSF-2.0), SymPy (BSD-3-Clause), NetworkX (BSD-3-Clause), Jinja2 (BSD-3-Clause),
fsspec 2026.6.0 (BSD-3-Clause), MarkupSafe (BSD-3-Clause), and mpmath (BSD-3-Clause).
Each exact wheel and SHA-256 is recorded in `fingering/dependencies.json` and
`fingering/requirements.lock`; package license texts are distributed inside
their installed distribution metadata under `.tools/fingering/python/Lib/site-packages/` (including torch bundled third-party notices). CPython LICENSE.txt is shipped beside python.exe. pip and wheel caches are not distributed.

# Microsoft app-local Visual C++ runtime (conditional)

The portable inference environment requires unchanged x64 MSVCP140.dll,
VCRUNTIME140.dll and VCRUNTIME140_1.dll, version 14.44.35211.0. Official archive,
DLL and EULA hashes are pinned in fingering/dependencies.json. Archive-only
extraction never executes the redistributable installer. The original license
is retained beside Python as MSVC-LICENSE.rtf when these binaries are included.
Redistribution requires applicable valid Visual Studio license rights; the
standalone redistributable end-user license does not independently grant rights
to share these files combined with another application. Setup and packaging
require explicit -ConfirmRedistributionRights. Microsoft Corporation retains
all rights. Applicable terms and redistribution list:
https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files
https://learn.microsoft.com/en-us/visualstudio/releases/2022/redistribution
https://visualstudio.microsoft.com/license-terms/vs2022-cruntime/
Windows/UCRT DLLs are provided by Windows and are not copied into this package.

Default windows-prerequisite packages redistribute none of MSVCP140.dll, VCRUNTIME140.dll or VCRUNTIME140_1.dll (including files originally present in the Python archive). The Microsoft license/DLL extraction mode above applies only to the explicitly confirmed optional bundled mode; it was not used for this release.
