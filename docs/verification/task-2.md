## Implementation
- Added an engine-owned native metronome with bounded 63-command SPSC queue (control mutex serializes producers), native sample-frame scheduling and sixteen preallocated independent click voices.
- Added all specified controls, canonical snapshot and settings-only persistence object, config/start/stop commands, stopped-only exact beat hook and control-thread Follow adapter.
- Three original waveforms generated in construction; callback only reads precomputed samples. No callback locks, allocations, JSON, disk/network or logging. Click voices never borrow live/playback/example sampler voices.
- Starts at next render-block frame immediately; count-in events/clicks mark configured first bars and then seamlessly continue. Repeated start preserves position. Tempo changes next beat; meter/subdivision/swing/accent changes next bar. Stop clears click tails only; Panic/service shutdown clears global clicks. Piano source/bus stops do not stop metronome.
- Follow consumes tempo/meter/beat/absolute frame, clamps past frames to next render block and retains last tempo on transport stop (no adapter call necessary for stopped transport).
